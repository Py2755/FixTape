# FixTape v0.1.13

Focused follow-up release for compressed debugging briefs and root-cause lenses.

## Highlights

- Added `fixtape digest` for compact per-session briefs.
- Added generated session digest artifacts in JSON and Markdown.
- Added `fixtape lenses` to roll history up into repeat root-cause views and common next steps.

## Why this release matters

FixTape now gets closer to an engineering memory system instead of just a session archive.
You can look at one session as a compact debugging brief, or scan the whole history through root-cause lenses without re-reading every timeline.
