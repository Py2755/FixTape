# FixTape v0.1.14

Focused follow-up release for regression memory and fix outcome analytics.

## Highlights

- Added `fixtape regressions` for recurring regression-test memory across repeated failures.
- Added `fixtape outcomes` for verdict and fix-rate analytics across failure families.
- Extended the session index with regression draft fields so outcome views can reason about repro readiness and test readiness.

## Why this release matters

FixTape now helps teams answer two harder questions:
which failure classes keep deserving a real regression test, and which kinds of incidents the team actually closes versus repeatedly hands off.
