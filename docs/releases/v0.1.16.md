# FixTape v0.1.16

Focused follow-up release for incident triage and kickoff bundles.

## Highlights

- Added `fixtape triage` to match a current signal against historical playbooks, recipes, hotspots, and sessions.
- Added `fixtape kickoff` to start a new session with a generated incident kickoff bundle.
- Added generated kickoff artifacts in JSON and Markdown for early-session guidance.

## Why this release matters

FixTape no longer waits until the end of the investigation to become useful.
It can now help at the first minute of a new incident by pointing to the most relevant historical playbook, likely area, and repro path.
