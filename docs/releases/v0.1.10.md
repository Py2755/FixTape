# FixTape v0.1.10

Focused follow-up release for separate packaging and publishing.

## Highlights

- Added dedicated GitHub Actions workflows for CLI and VS Code extension packaging.
- Added publishing docs for building wheels, sdists, and `.vsix` artifacts.
- Aligned package versions across Python metadata, runtime version, and extension metadata.

## Why this release matters

FixTape now looks and behaves more like a real distributable product instead of just a source repository.
The CLI and the VS Code extension can be packaged independently, and the repository documents that release flow clearly.
