# FixTape v0.1.0

First public release of FixTape.

## Highlights

- Local-first CLI for capturing debugging sessions.
- Structured session lifecycle with `start`, `note`, `run`, `attach`, `snapshot`, `finish`.
- Generated artifacts:
  - `debug-summary.md`
  - `repro.ps1` / `repro.sh`
  - `regression-test.todo.md`
  - `timeline.json`
- Search and revisit old sessions with `list`, `show`, and `search`.
- Git-aware context capture and diff snapshots.
- Test suite plus GitHub Actions CI.

## Why this release matters

FixTape's first release is already useful without any AI integration.
It captures the real debugging trail and turns it into something a human teammate can reuse, review, and build on.

## Next areas

- shell integration for lower-friction capture,
- richer trace extraction,
- search improvements,
- IDE integrations,
- AI-assisted summarization.
