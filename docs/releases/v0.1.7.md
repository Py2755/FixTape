# FixTape v0.1.7

Focused follow-up release for cross-session indexing.

## Highlights

- Added a local cross-session index at `.fixtape/session-index.json`.
- Added `fixtape reindex` to rebuild the index from existing sessions.
- `list` and `search` now operate on the maintained index instead of walking every session each time.

## Why this release matters

FixTape is now better positioned for larger local histories.
This release lays the groundwork for faster retrieval, richer cross-session intelligence, and future indexing-based features.
