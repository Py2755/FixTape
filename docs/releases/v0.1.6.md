# FixTape v0.1.6

Focused follow-up release for editor visibility.

## Highlights

- Added a lightweight VS Code extension under `extensions/vscode`.
- The extension shows active and recent FixTape sessions in a dedicated activity bar view.
- Open `handoff.md`, `debug-summary.md`, or reveal the session folder directly from the editor.

## Why this release matters

FixTape is now easier to revisit during normal coding flow.
The CLI remains the capture engine, while the extension makes session output visible inside the editor without rebuilding the product around IDE-specific logic.
