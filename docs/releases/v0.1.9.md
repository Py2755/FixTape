# FixTape v0.1.9

Focused follow-up release for direct ref linking UX.

## Highlights

- Added `fixtape link` for linking tickets, issues, commits, PRs, and other refs.
- Added `fixtape refs` to inspect linked refs for the current or latest session.
- Search can now match linked refs directly.

## Why this release matters

FixTape sessions now connect more cleanly to the surrounding work:
tickets, commits, issues, and related references are easier to add, easier to inspect, and easier to retrieve later.
