# FixTape v0.1.1

Follow-up release after the first public launch.

## Highlights

- Added session search field filters.
- Added `shell-init` for PowerShell and POSIX helper functions.
- Added a visual demo asset and demo script to improve the first-run repository experience.
- Added roadmap documentation for upcoming iterations.

## Why this release matters

This release makes FixTape easier to try, easier to demo, and easier to use repeatedly from a real shell workflow.
