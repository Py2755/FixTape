# FixTape v0.1.15

Focused follow-up release for repeatable playbooks and fix recipes.

## Highlights

- Added `fixtape playbooks` for family-level troubleshooting playbooks.
- Added `fixtape recipes` for concrete repeated-failure recipes with triggers, repro commands, and artifact capture hints.
- Turned historical regressions and digests into reusable operational guidance instead of only analytics.

## Why this release matters

FixTape now starts to behave like a living debugging handbook.
When the same class of incident returns, the repo can suggest how to start, what to capture, and which repro path has worked before.
