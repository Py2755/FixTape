# FixTape v0.1.3

Focused follow-up release for smarter search.

## Highlights

- Search now ranks stronger matches above weaker ones.
- Title and summary hits naturally outrank lower-signal matches.
- `fixtape search` now prints compact field-labeled snippets for faster scanning.

## Why this release matters

FixTape becomes more useful as session history grows.
This release makes previous debugging work easier to revisit without scrolling through noisy raw output.
