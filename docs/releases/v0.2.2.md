# FixTape v0.2.2

FixTape suggestions now understand the kind of incident that is starting.

## Highlights

- `fixtape suggest-start` now scores incident types such as test regression, Python runtime exception, HTTP/API failure, SQL failure, and infra-style command failure.
- Generic `process_failure` no longer overwhelms stronger evidence from more specific incident classes.
- Historical family playbooks, hotspots, and outcome rates now boost suggestion confidence and can switch the recommendation from `start` to `kickoff`.
- `fixtape doctor` now shows the same enriched recommendation, including incident type, confidence, first move, and recommended mode.

## Why this matters

The previous suggestion layer could tell that "something is going wrong."

This release moves it closer to "what kind of incident is starting, and do we already know how this kind usually begins?"

That makes the suggestion system materially more useful in real debugging flow, especially once a repository has a few repeated incident families.
