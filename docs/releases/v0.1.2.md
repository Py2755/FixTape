# FixTape v0.1.2

Focused follow-up release for lower-friction shell usage.

## Highlights

- Added opt-in shell hook capture mode through `fixtape shell-init --mode all`.
- Shell hooks can now capture command line, exit code, and working directory automatically during an active session.
- Session summaries now show whether a command came from explicit `fixtape run` capture or from shell hooks.

## Why this release matters

This release addresses the biggest day-to-day friction in the current CLI workflow.
Developers can keep the reliable explicit capture path, while also enabling a lighter command-memory mode during long debugging sessions.
