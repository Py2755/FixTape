# FixTape v0.1.8

Focused follow-up release for smarter failure parsing.

## Highlights

- Added parsed artifact extraction for traces, logs, and captured command outputs.
- Added `generated/parsed-artifacts.json`.
- `debug-summary.md` and `handoff.md` now surface parsed failure signals directly.

## Why this release matters

FixTape now preserves not only the debugging trail, but also a structured view of the failure itself.
This makes sessions easier to skim, hand off, and build follow-up automation around.
