# FixTape v0.1.12

Focused follow-up release for history-level cross-session intelligence.

## Highlights

- Added `fixtape clusters` for grouping related incidents across accumulated debugging history.
- Added `fixtape hotspots` for surfacing repeat-problem areas by file, exception, failure family, status code, or fingerprint.
- Turned pairwise similarity into a higher-level overview of where the same classes of failures keep coming back.

## Why this release matters

FixTape now moves beyond session memory into debugging analytics.
Instead of only helping you revisit one investigation at a time, it can now show where the team keeps paying the same debugging tax across multiple sessions.
