# FixTape v0.1.11

Focused follow-up release for smarter failure parsing and second-level cross-session intelligence.

## Highlights

- Added structured parsing for Python, Node, Java, HTTP, SQL, pytest, and command-level failures.
- Added session similarity lookup with `fixtape similar`.
- Added recurring failure clustering with `fixtape patterns`.
- Added signal-aware search through `fixtape search --field signals`.

## Why this release matters

FixTape now remembers more than raw notes and commands.
It can extract reusable failure fingerprints from traces and logs, then use those fingerprints to find related past investigations instead of treating every debugging session like an isolated artifact.
