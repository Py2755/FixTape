# FixTape v0.2.0

FixTape now has a zero-touch flight recorder.

## Highlights

- `fixtape doctor` shows the current pre-session recorder state.
- `fixtape promote --include-last 40m` imports recent buffered commands into the active session.
- `fixtape capture` records full stdout/stderr even before a FixTape session exists.
- `fixtape start`, `fixtape kickoff`, and `fixtape finish` now accept `--include-last ...` so late session starts are recoverable.

## Why this matters

The biggest workflow failure in session-based debugging tools is forgetting to start capture early enough.

FixTape now keeps a rolling local command buffer under `.fixtape/flight-recorder`, so the last stretch of debugging can be promoted into a proper session after the fact.
