# FixTape v0.1.4

Focused follow-up release for better team handoff.

## Highlights

- Added richer handoff bundles for `fixtape export`.
- Export archives now open with top-level handoff-first files:
  - `HANDOFF.md`
  - `SUMMARY.md`
  - `REPRO_SCRIPT`
  - `REGRESSION_TEST_TODO.md`
  - `metadata.json`
- Added `--ref` support on `fixtape finish` for linking tickets, commits, or other related identifiers.
- Generated `handoff.md` for every finished session.

## Why this release matters

FixTape is no longer just a personal debugging memory tool.
This release makes it substantially better for handing work to another engineer, documenting a fix path, and preserving links to surrounding work items.
