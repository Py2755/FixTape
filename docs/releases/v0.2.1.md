# FixTape v0.2.1

FixTape can now suggest when an investigation should become a real session.

## Highlights

- `fixtape suggest-start` looks at recent buffered commands and detects likely incident onset.
- Failure bursts and traceback-like signals now produce a concrete `start` and `kickoff` recommendation.
- Shell hooks can print a one-line suggestion automatically, with cooldown suppression to avoid spam.
- `fixtape doctor` now shows the best current start recommendation alongside recorder status.

## Why this matters

Zero-touch capture solves "I forgot to start FixTape."

This release solves the next UX gap: "I can see the buffer, but when should I turn it into a real session?"

Instead of forcing aggressive auto-start behavior, FixTape now suggests the session boundary at the moment recent failures actually look like an incident.
